# Tuning Labs Audio Helper — releases

Release binaries and checksums for the Tuning Labs Audio Helper (Windows desktop app).

From 0.11.0 the helper reads https://tuninglabs.net/helper/latest.json at launch and installs a newer release from this repository after verifying the file size and SHA-256 in that manifest. Each release carries the exe and a SHA256SUMS file.

Source lives in the private Tunning-lab repository.
